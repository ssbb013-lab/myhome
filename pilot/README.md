# בית נוצץ - פיילוט למשפחות נוספות

## גבולות הפרויקט
- ענף הפיתוח: `pilot/multi-family`. **אין למזג ל-`main` לפני בדיקות בידוד**.
- מסד נתונים ריק לפיילוט בלבד: `beit-notzetz-pilot` (D1 UUID: `10db330a-2d04-4f3f-b4f0-332c678930c2`).
- האתר `myhome.helpsec.net`, המשתמשים והמידע הקיימים **לא מועתקים** לפיילוט.
- הרשמת משפחות תהיה ידנית ובאישור מנהל-על. לא פותחים הרשמה ציבורית.
- אין לפרסם סביבת preview שמחוברת ל-D1 של המשפחה הקיימת.

## ארכיטקטורה
1. זהות משתמש: חשבון הורה עם סיסמה מגובבת (KDF מתאים), אימות הפעלה ו-session חתום/מאוחסן בצד השרת.
2. קישור משתמש למשפחה: `pilot_memberships`. כל פעולה בשרת מבצעת בדיקת חברות ואישור משפחה פעילה.
3. ילדים: `pilot_children` לפי `family_id`, ללא שמות מובנים בקוד.
4. מצב משימות: `pilot_family_state` עם מפתח `family_id` ומספר revision לאופטימיות.
5. שוברים ובנק: רשומות מופרדות לפי `family_id` עם מפתחות מורכבים, זיכוי אטומי ומעקב.
6. חנות, תמונות, פרסים, קמפיינים ודוחות: חייבים לקבל `family_id` מה-session המאומת בלבד; לא מפרמטר דפדפן.
7. מנהל-על: מטא-דאטה בלבד (משפחות/סטטוס/תאריך יצירה), לא גישה אוטומטית למידע הילדים.
